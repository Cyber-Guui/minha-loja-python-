# Minha Loja - Python

Meu primeiro projeto em Python, criado durante meus estudos para praticar lógica de programação e desenvolver um pequeno sistema de cadastro de produtos.

## Funcionalidades

- Cadastro de produtos
- Registro de preço e quantidade
- Cálculo automático do total
- Desconto de 10% para compras de €200 ou mais
- Cadastro de vários produtos
- Resumo final da compra
- Cálculo do total geral

## Tecnologias

- Python

## Conceitos praticados

- Variáveis
- `input()`
- `int()`
- `float()`
- `if` e `else`
- `while`
- listas
- `append()`
- `for`
- f-strings

## Como funciona

O usuário informa o nome do produto, o preço e a quantidade.

O programa calcula o valor total do item e aplica 10% de desconto caso a compra seja de €200 ou mais.

Também é possível cadastrar vários produtos e visualizar um resumo final da compra.
